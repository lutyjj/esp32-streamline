StreamLine bridge

Lossless recordings

Preserve the analog source received by this bridge as 48 kHz, 16-bit stereo WAV. This page manages files stored on the bridge; capture, audio, and network settings stay in each device's console.
Checking bridge

Recording is off

Configure a writable recording directory and a recording token, then restart the bridge. Live WAV streaming continues unchanged while recording is disabled.

Standalone: set --recordings-dir and STREAMLINE_RECORDING_TOKEN. Home Assistant: enable recordings in the add-on configuration and set its token.

Unlock recordings

Use the recording token configured on this bridge. It stays in this browser tab.

New recording

Start first, then play the source. The file begins with the first audio packet and stops at the last received packet. This is an analog recording, not a bit-perfect CD extraction.
