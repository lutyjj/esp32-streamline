Flash ESP32 StreamLine

Install the latest firmware onto your ESP32 Audio Kit directly from this page — no toolchain required.

Web Serial isn't supported here. Open this page in desktop Chrome, Edge, or Firefox 151+. This must be served over HTTPS to flash a device.
Plug the board in over USB, then click above and pick its serial port.

Before you start

  • Use desktop Chrome, Edge, or Firefox 151+ — they support Web Serial. Safari and mobile browsers don't.
  • Connect the ESP32 Audio Kit to your computer with a data-capable USB cable.
  • Some boards need a USB-to-UART driver (CP210x or CH340) installed first.
  • The installer erases the device, then writes a clean -full.bin (the OTA-capable two-slot layout). Any saved Wi-Fi, console secret, and audio settings are cleared, so the device always starts fresh in setup mode.

After flashing

  1. The device boots an open esp32-streamline-XXXX setup network.
  2. Connect to it and open http://192.168.4.1/.
  3. Enter your Wi-Fi, the bridge's TCP target, and a console secret, then save.

Full walkthrough in the project README.

Prefer the command line?

Download streamline-X.Y.Z-full.bin from Releases and flash with esptool:

esptool.py -p /dev/ttyUSB0 -b 460800 write_flash 0x0 streamline-X.Y.Z-full.bin
